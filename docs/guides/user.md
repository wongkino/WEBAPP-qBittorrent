# 使用手冊

部署者需先依 [deployment.md](deployment.md) 設定 Docker、qBittorrent 與反向代理登入。

## 第一次使用

1. 開啟反向代理提供的 Web App 網址並完成代理登入。
2. 進入後會自動載入 qBittorrent 的下載列表。
3. 可選擇 Safari 的「分享 → 加入主畫面」安裝 PWA。

## 功能

- 下載列表每約 4 秒更新，可排序、批次暫停／繼續／刪除與調整分類。
- 在下載分頁貼上 magnet 或 torrent URL 以新增下載。
- RSS 分頁可新增、重新整理或移除 qBittorrent RSS 訂閱，並將文章加入下載。
- 語系與日間／夜間設定會保存在瀏覽器。

## 常見狀況

| 現象 | 處理方式 |
|------|----------|
| 未登入或被拒絕 | 請在反向代理完成登入，並確認其規則涵蓋 `/api/qb/*`。 |
| 列表空白或操作失敗 | 部署者檢查 `QBITTORRENT_URL`、qB 帳密與容器日誌。 |
| 誤刪檔案 | 「刪檔」會連下載檔一起刪除；只移除任務請使用「移除」。 |
